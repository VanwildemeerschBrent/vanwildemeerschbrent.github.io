Building a Modern Portfolio with SvelteKit

Creating a portfolio website is an essential step for any developer. In this post, I’ll share how I built my portfolio using SvelteKit and the lessons I learned along the way.

Why SvelteKit?

SvelteKit offers several advantages for building a portfolio:

  • Performance: Svelte compiles to vanilla JavaScript, resulting in smaller bundle sizes
  • Developer Experience: Intuitive syntax and built-in features like routing
  • SEO-Friendly: Server-side rendering out of the box
  • Static Site Generation: Perfect for portfolios that don’t need dynamic data

Key Features

1. Lazy Loading Components

I implemented lazy loading to improve initial page load times:

import LazyLoad from '$lib/components/LazyLoad.svelte';

<LazyLoad>
	<About />
</LazyLoad>;

This ensures components only load when they’re visible in the viewport.

2. Image Optimization

Using vite-imagetools, I automatically optimize images:

import HeaderImg from '$lib/assets/header-bg.jpg?imagetools&width=1920&format=webp';

3. Performance Optimizations

  • Preload critical resources
  • Efficient caching strategies
  • Minimized layout shifts
  • Fast LCP (Largest Contentful Paint)

Lighthouse Score

After optimization, the site achieves:

  • Performance: 95+
  • Accessibility: 100
  • Best Practices: 100
  • SEO: 100

Conclusion

Building with SvelteKit has been a great experience. The framework’s simplicity combined with powerful features makes it perfect for portfolio sites.
